ARENA

A simple terminal-based RPG written in C.
Still has bugs but idgaf.

About

ARENA is one of my first personal programming projects. It is a turn-based combat game where players fight monsters, manage their health, and level up as they progress.

Features
Turn-based combat
Monster progression
Player leveling system
Health and healing mechanics
Randomized enemy attacks
Technologies
C
Standard C Library
Purpose

This project was created as a learning exercise while exploring C programming, functions, loops, conditional statements, and basic game logic.

Status

Work in progress. Improvements and new features will be added as I continue learning.
